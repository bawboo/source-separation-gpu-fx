# 請幫我測一下 Music SSP FX（Intel Mac）

這是一個把歌曲分離成人聲與伴奏的小工具。它在 Apple Silicon 的 Mac 上測過了，
但**沒有任何人在真正的 Intel Mac 上跑過**——我手上沒有那種機器。

想請你花大約 **15 分鐘**幫忙跑一次，告訴我結果。不需要懂程式，照下面做就好。
中間有任何一步看不懂或跟描述不一樣，**那本身就是有用的回報**，直接告訴我。

---

## 先做這一步（30 秒）

打開「終端機」（在「應用程式 → 工具程式」裡，或按 `Command + 空白鍵` 打
「終端機」），把下面整段貼進去按 Enter，然後把印出來的東西傳給我：

```bash
sysctl -n machdep.cpu.brand_string; sysctl -n hw.optional.avx2_0; sw_vers -productVersion; uname -m
```

四行分別是：處理器型號、有沒有 AVX2、macOS 版本、晶片架構。

**這一步最重要。** 我們能在 Apple Silicon 上模擬 Intel 版，但模擬出來的環境沒有
AVX2 這個指令集，而真正的 Intel Mac 有。所以你那台會走到一條我們一次都沒跑過的
程式碼——這就是為什麼需要你。第二行印 `1` 代表有 AVX2，印 `0` 或報錯代表沒有，
兩種都可以，只要告訴我是哪種。

---

## 1. 安裝

打開我傳給你的 `MusicSSPFX-0.0.10-x86_64.dmg`，把「Music SSP FX」拖到旁邊的
Applications 資料夾。

## 2. 第一次開啟

雙擊會被 macOS 擋下來，說「無法打開，因為無法驗證開發者」。
**這是正常的**，因為這個程式沒有付費的 Apple 開發者簽章，不是因為它有問題。

請這樣開：

1. 打開「系統設定」→「隱私權與安全性」
2. 捲到最下面，會看到「已阻止 Music SSP FX」
3. 按「仍要打開」，再按一次「打開」

只要做這一次。（macOS 14 以前：在「應用程式」裡對它按右鍵，選「打開」。）

**請告訴我你實際看到的畫面跟上面一不一樣。** 不同的 macOS 版本說法不太一樣，
如果你卡在這裡，那是我要修的東西。

## 3. 分離一首歌

準備一個音樂檔（mp3、m4a、wav 都可以，影片檔也行）。

1. 按藍色的「匯入音訊 / 影片」，選那個檔案
2. 下面那排**保持「一般」**
3. 按「僅匯出伴奏」，選要存到哪裡

按下去就開始跑了，進度列會動。**沒有「分離」按鈕，匯出就是開始。**

**第一次會先下載模型檔（幾百 MB），要網路。** 下載完之後畫面可能會有一段時間
沒有動靜——程式要把模型載進記憶體。請不要強制結束。

⚠️ **「高品質」那顆先不要按。** 它能用，但在 Intel Mac 上一首歌要跑 50 分鐘左右。
等基本的跑通了，你有興趣再說。

## 4. 聽一下結果

打開存出來的檔案，確認：

- 有聲音（不是一片安靜）
- 人聲確實被拿掉了，伴奏還在
- 沒有明顯的爆音或雜訊

## 請回報這些

1. **第一步那四行輸出**（處理器、AVX2、macOS 版本、架構）
2. 第 2 步的畫面跟說明一不一樣，有沒有卡住
3. **一首歌大概跑多久**（從按下「僅匯出伴奏」到存檔完成，估個大概就好）
4. 那首歌多長
5. 出來的聲音對不對
6. 過程中有沒有出現任何錯誤訊息、閃退、或是等超過十分鐘還沒反應

**「都正常」也是完整的回報**，不用特別找問題。

## 如果它閃退了

閃退的話系統會留下一份紀錄，請這樣拿給我：

1. 打開「主控台」（Console.app，在「應用程式 → 工具程式」裡）
2. 左邊選「當機報告」
3. 找名字裡有 `Music SSP FX` 的，時間最接近的那一份
4. 對它按右鍵 → 「在 Finder 中顯示」，把那個檔案傳給我
