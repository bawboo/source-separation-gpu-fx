# 請幫我測一下 Music SSP FX（Intel Mac）

這是一個把歌曲分離成人聲與伴奏的小工具。它在 Apple Silicon 的 Mac 上測過了，
但**沒有任何人在真正的 Intel Mac 上跑過**——我手上沒有那種機器。

想請你花大約 **15 分鐘**幫忙跑一次，告訴我結果。不需要懂程式，照下面做就好。
中間有任何一步看不懂或跟描述不一樣，**那本身就是有用的回報**，直接告訴我。

---

## 先做這一步（30 秒）——**做完先傳給我，不要急著安裝**

打開「終端機」（在「應用程式 → 工具程式」裡，或按 `Command + 空白鍵` 打
「終端機」），把下面整段貼進去按 Enter，然後把印出來的東西傳給我：

```bash
echo "處理器  : $(sysctl -n machdep.cpu.brand_string)"
echo "AVX2    : $(sysctl -n hw.optional.avx2_0 2>/dev/null || echo '(沒有這個項目)')"
echo "macOS   : $(sw_vers -productVersion)"
echo "架構    : $(uname -m)"
```

會印出四行，每行前面都有標籤。整段複製給我就好，不用挑。

**⚠️ 如果「macOS」那行小於 12，請先停在這裡告訴我，不要安裝。** 這個版本需要
macOS 12（Monterey）以上，更舊的系統會失敗——而且失敗的樣子看不出是系統版本的
問題。先確認這一點，可以省下你二十分鐘。

**這一步最重要。** 我們能在 Apple Silicon 上模擬 Intel 版，但模擬出來的環境沒有
AVX2 這個指令集，而真正的 Intel Mac 有。所以你那台會走到一條我們一次都沒跑過的
程式碼——這就是為什麼需要你。AVX2 那行印 `1` 代表有、`0` 或「(沒有這個項目)」
代表沒有，兩種都可以，只要讓我知道是哪種。

## 1. 安裝

打開我傳給你的 `MusicSSPFX-0.0.12-x86_64.dmg`，把「Music SSP FX」拖到旁邊的
Applications 資料夾。

## 2. 第一次開啟

先雙擊看看，**兩種結果都有可能，都是正常的**：

- **直接開起來了** → 跳過這一段，往下做第 3 步。
- **被 macOS 擋下來**，說「無法打開，因為無法驗證開發者」 → 也是正常的，因為這個
  程式沒有付費的 Apple 開發者簽章，不是因為它有問題。請這樣開：

  1. 打開「系統設定」→「隱私權與安全性」
  2. 捲到最下面，找到提到 Music SSP FX 被阻擋的那一段
  3. 按那一段旁邊的「仍要打開」，再按一次「打開」

  只要做這一次。（macOS 14 以前：在「應用程式」裡對它按右鍵，選「打開」。）

**請告訴我實際是哪一種。** 我們自己的機器已經跑過太多次、狀態不乾淨，回答不了
「一台全新的機器會怎樣」——你那台才能。

上面的文字也可能跟你螢幕上的不完全一樣，每個 macOS 版本的措辭都在變。只要找到
提到這個 App 被擋住的那一段就對了。**如果你卡在這裡，請把畫面拍給我。**

## 3. 分離一首歌

準備一個音樂檔（mp3、m4a、wav 都可以，影片檔也行）。

1. 按藍色的「匯入音訊 / 影片」，選那個檔案
2. 下面那排**保持「高品質」**（預設就是）
3. 按「僅匯出伴奏」，選要存到哪裡

按下「僅匯出伴奏」會**先跳出存檔對話框**，選好位置之後才開始跑，進度列才會動。
**沒有「分離」按鈕，匯出就是開始。**

**第一次會先下載模型檔（幾百 MB），要網路。** 下載完之後畫面可能會有一到兩分鐘
完全沒有動靜——程式要把模型載進記憶體。**請不要強制結束**，第二次之後就快了。

旁邊那顆**「超高品質」在你那台會是灰的、按不下去**，這是正常的——它需要顯示卡，
在 Intel Mac 上一首 4 分鐘的歌要跑約一小時，所以我們沒有開放。滑鼠移上去會說明。

## 4. 聽一下結果

打開存出來的檔案，確認：

- 有聲音（不是一片安靜）
- 人聲確實被拿掉了，伴奏還在
- 沒有明顯的爆音或雜訊

## 如果它閃退了

閃退的話系統會留下一份紀錄，請這樣拿給我：

最簡單的方法是用 Finder 直接去拿：按 `Command + Shift + G`，貼上

```
~/Library/Logs/DiagnosticReports
```

按 Enter，找名字裡有 `Music SSP FX`、時間最接近的那一份傳給我。

（也可以用「主控台」App，在左側找當機報告那一類，但每個 macOS 版本的名稱不太一樣，
上面那條路徑比較可靠。）
